Welcome to OntoJSON

Transform OWL/RDF ontologies into JSON Schema with ease

OntoJSON provides a powerful, configurable transformation engine that converts one or more semantic web ontologies into a JSON schema.

Purpose is to use ontologies without alterations (except of course the formal language) in conventional Web applications, rather than custom-made, non-interoperable schemas. Of course, the use of native ontology formats such as JSON-LD is encouraged.

This application is available as a web app or desktop app (for Windows and macOS; Linux version under preparation); see on GitHub.
