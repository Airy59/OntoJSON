OntoJSON Documentation

Quick Start

Web Interface

  1. Navigate to the Transform page
  2. Upload your ontology file or enter a URL
  3. Configure transformation options (optional)
  4. Click "Transform" to generate JSON Schema
  5. Download or copy the resulting schema

Command Line

# Transform a single ontology
owl2jsonschema transform input.ttl -o schema.json

# Transform multiple ontologies
owl2jsonschema transform onto1.ttl onto2.ttl -o composite.json

# Generate sample instances
owl2jsonschema generate-abox schema.json -n 10 -o instances.json

REST API

curl -X POST http://localhost:5001/api/transform \
  -H "Content-Type: application/json" \
  -d '{"source": "https://example.org/ontology.ttl"}'

Supported Formats

Input Formats

  • Turtle (.ttl) - Terse RDF Triple Language
  • RDF/XML (.rdf, .owl) - RDF XML syntax
  • JSON-LD (.jsonld) - JSON for Linked Data
  • N-Triples (.nt) - Line-based RDF format
  • N3 (.n3) - Notation3
  • RDFa - RDF in attributes

Output Formats

  • JSON Schema - Draft-07 (default), Draft-04, 2019-09, 2020-12
  • JSON - Generated instances
  • JSON-LD - Linked data format

Transformation Rules

OntoJSON applies various transformation rules to convert OWL/RDF constructs to JSON Schema:

OWL/RDF Construct JSON Schema Equivalent
owl:Class Object type with properties
rdfs:subClassOf allOf with $ref
owl:DatatypeProperty Property with type constraint
owl:ObjectProperty Property with $ref to object
owl:minCardinality minItems / required
owl:maxCardinality maxItems
owl:oneOf enum
owl:unionOf anyOf
owl:intersectionOf allOf
rdfs:label title
rdfs:comment description

Configuration Options

Rule Configuration

Each transformation rule can be individually enabled/disabled and configured:

{
    "rules": {
        "class_to_object": true,
        "labels_to_titles": {
            "enabled": true,
            "language": "en",
            "fallback_language": "en"
        },
        "property_cardinality": {
            "enabled": true,
            "strict": false
        }
    }
}

Global Options

  • language - Preferred language for multilingual content
  • base_uri - Base URI for resolving relative references
  • schema_version - JSON Schema specification version
  • include_metadata - Include ontology metadata in output
  • generate_examples - Generate example values for properties

Advanced Usage

Composite Ontologies

Combine multiple ontologies into a single schema:

from owl2jsonschema.services import TransformationService

service = TransformationService()
result = service.transform_multiple(
    sources=[
        "https://example.org/onto1.ttl",
        "https://example.org/onto2.ttl"
    ],
    composite_metadata={
        "title": "Combined Ontology",
        "description": "Merged ontologies for application"
    }
)

Pipeline Processing

Execute the full transformation pipeline:

# T-box → A-box → JSON instances
tbox_result, abox_result, json_result = service.full_pipeline(
    sources=["ontology.ttl"],
    generate_instances=True,
    instance_count=10,
    output_format="json"
)

Custom Rules

Extend OntoJSON with custom transformation rules:

from owl2jsonschema.rules import TransformationRule

class CustomRule(TransformationRule):
    def apply(self, ontology, schema):
        # Custom transformation logic
        return schema

# Register and use the custom rule
config = TransformationConfig()
config.add_rule(CustomRule())

Troubleshooting

Common Issues

Q: Transformation fails with "Parse error"
A: Ensure your ontology file is valid RDF. Try validating it with an RDF validator first.
Q: Missing properties in output schema
A: Check that the relevant transformation rules are enabled in your configuration.
Q: Labels/descriptions are in wrong language
A: Set the correct language preference in configuration options.
Q: Task stays in "pending" status
A: For async processing, ensure Redis/Celery are running. Otherwise, use synchronous mode.

Debug Mode

Enable debug logging for detailed transformation information:

import logging
logging.basicConfig(level=logging.DEBUG)

# Or in CLI
owl2jsonschema transform --debug input.ttl
